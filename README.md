**🏋️ Gym Website – Frontend Project**

A modern and responsive Gym / Fitness Website built using HTML and CSS, focused on clean UI, smooth layout, and a high-energy dark theme suitable for fitness brands.

This project showcases core frontend development skills and real-world layout fixing techniques.

🚀 Features

Modern dark-themed gym UI

Responsive layout for different screen sizes

Fixed scroll behavior (no unwanted page overflow)

Clean card-based sections

Hero section with CTA

Facilities, Services, About & Contact sections

Free Trial call-to-action section

🛠️ Tech Stack

HTML5

CSS3

Flexbox & Grid

Responsive design principles
